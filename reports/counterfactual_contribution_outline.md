# 将 counterfactual 作为论文主打之一：备选论证大纲

**状态：备选方案，未用于本轮 LaTeX 修订。** 当前论文按此前 ars-outline 结构修订，仍将 CF 定位为已有方法集成框架内的信用分配比较。本文件只记录另一种可供后续确认的研究重心，不代表已经证明其新颖性、有效性或普适性。

## 1. 研究问题与贡献层级

**候选研究问题：** 在具有硬可行动作映射和累计风险成本的分解配置策略中，孤立分支收益与组合贡献有何差异，基于可行中性替换路径的开环信用如何改变学习结果？

三条主线可以并列组织，但承担不同角色：

| 主线 | 核心问题 | 证据边界 |
| --- | --- | --- |
| CAOSD／simplex | 如何保证每个执行配置满足约束？ | 归属于已有 CAOSD 方法的两组可行性结论；不是本项目原创算法 |
| RCPO-inspired learning | 如何按已实现成本调整风险压力？ | 已实现自适应乘子；当前评估不支持可靠满足风险目标 |
| Counterfactual credit | 如何评价依赖分支对组合结果的贡献？ | 已实现开环影子路径；有效性与作用归因仍需受控验证 |

CF 可以获得与其他模块相当的叙事重要性；目前不能宣称三者具有同等成熟的理论保证，也不能将其并列为三项原创算法。

## 2. 候选章节论证

### Introduction

- 从硬约束配置的分解策略出发，说明共同结果下的分支信用问题。
- 明确 standalone 评价独立投资轨迹，未必评价实际可行组合中的贡献。
- 将研究目标落在信用方案的比较与机制解释，不预设 CF 优于其他方法。
- 保留一般 constrained allocation RL 主线；经验结论限于投资组合实例。

### Problem Formulation

- 保留完整状态与策略观察、配置记忆、路径风险记忆及非前视时序。
- 区分硬可行集、期望累计成本与实验评价指标。
- 将共享外生市场轨迹列为当前影子路径计算的条件；不宣称直接支持任意动作依赖环境。

### Preliminaries

- 简述并明确归属 CAOSD、PPO 与 RCPO。
- 衔接 difference rewards 与 COMA，解释默认动作替换与条件期望基线的区别。
- 不从多智能体文献直接移植无偏梯度、降方差或收敛结论。

### Proposed Method

1. 给出 surrogate action、可行映射与自回归依赖接口。
2. 对照 standalone、共享全局信用与开环 CF 的评价对象。
3. 定义中性替换、重新映射和各自持久的配置／财富／峰值状态。
4. 区分 CF-R、CF-C、CF-RC，明确质量权重、归一化、训练掩码和熵正则。
5. 解释开环路径差异包含历史替换影响，不是单步因果效应。
6. 伪代码区分实际成本的全局乘子更新与分支差分信用。

### Experiments

以下仅为后续可能需要的验证，未在本轮执行：

- 重评已有检查点，核验修复初始财富峰值后的 MDD、区间和风险排名。
- 设计受控消融，隔离信用信号、质量权重和熵正则的贡献。
- 在可比较的条件分支 surrogate 下加入共享全局信用基线；另行区分其与联合似然 PPO 基线的差别。
- 通过多个训练种子检验稳定性，区分训练随机性与测试市场变异。
- 检查替换造成的配置变化、分支信号分布、风险行为与额外计算开销。
- 仅在希望主张跨任务普适性时增加其他配置任务；没有这类验证时保留实例边界。

## 3. 当前证据与未解决问题

- 现有结果只支持信用训练方案具有不同的条件表现，尚不能归因于 CF 信号本身。
- Dirichlet CF-R 的归档平均相对财富较高，但相对 standalone 的配对收益优势不明确，且换手更高。
- Gaussian CF-C 存在成本改善线索；MDD 相关结论需等待修复后的重新评估。
- CF-RC 没有一致优势，不应假定收益与成本差分具有叠加收益。
- 当前比较同时涉及质量权重、掩码、熵正则及 critic 输入差异。
- 自回归后续动作依赖被替换分支，不能直接沿用同时独立采样下的基线抵消论证。
- 持久影子轨迹造成历史差异；当前机制不是闭环替代策略评价。
- 当前训练与评估不能证明已可靠满足路径风险预算。

## 4. 后续采用条件

若不新增实验，CF 宜作为重要的探索性比较与方法诊断内容。若希望主张 CF 本身带来稳定收益、风险改善或更有效的信用估计，需要先补齐相应消融、跨种子复现和机制证据。若希望主张无偏性、目标等价或收敛性质，则必须提供针对当前自回归、持久影子历史和分支 surrogate 的证明。

作者确认采用本方向前，不据此强化论文标题、摘要、贡献列表或结论。
